## THE RULE (DESIGN.md RT-iii, enforced structurally)

**Fixture files contain NO result values.** Comparison targets live ONLY in
**oracle-run artifacts** (`fixtures/oracle/*.json`, schema
`subtropica-oracle-run-v1`) carrying full provenance stamps.
`SubTropica.load_oracle_artifact` REFUSES fixture files and stamp-less files, so
a fixture-embedded value cannot reach the comparator by construction.
Comparisons against upstream-stored values (HF test refs, Long-suite refs)
are REGRESSION, never VALIDATION — those are not even stored here.
